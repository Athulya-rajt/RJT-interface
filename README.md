# ReconJT – Web Dashboard

**ReconJT** is a cybersecurity reconnaissance tool developed by **Joel T Biju**. It helps gather publicly available information about target domains through reconnaissance techniques such as WHOIS, NSLOOKUP, and DIG.

## About This Project

This repository contains the **web-based user interface (UI) for ReconJT**, designed and developed by **Athulya Raj T** using Flask, HTML, CSS, and JavaScript.

The current version focuses on the dashboard design, navigation, and user interface. It is a frontend/UI implementation and is **not yet integrated with the actual ReconJT reconnaissance engine**. Real scanning and data collection functionality are not currently implemented.

## Contributors

- **Original ReconJT Tool Developer:** [Joel T Biju](https://github.com/joeltbiju)
- **Web Dashboard UI Developer:** [Athulya Raj T](https://github.com/athulya-rajt)

*This project is an independent web interface design for the existing ReconJT tool. It does not claim to implement the original tool's functionality.*
